# ACC102 Track 2: Apple Stock Data Analysis Project

## 1. Problem & User
This project analyses Apple’s historical stock price and volatility for finance students and beginner investors. The goal is to show clear price trends and daily return patterns using Python.

## 2. Data
- Data source: Local CSV file (AAPL.csv) – company report–style historical financial data
- Access date: April 2026
- Key fields: Date, Open, Close, Adj Close, Volume

## 3. Methods
1. Load local CSV data using pandas
2. Clean and select key financial columns
3. Calculate daily return and 50-day moving average
4. Generate descriptive statistics
5. Visualise price trend and return volatility
6. Export cleaned dataset

## 4. Key Findings
- Apple’s adjusted closing price shows an overall upward trend
- Daily returns fluctuate within a stable volatility range
- The 50-day moving average smooths short‑term noise for trend identification
- Most daily returns remain within ±2 standard deviations

## 5. How to Run
1. Place AAPL.csv in the same folder as the notebook
2. Run each cell step by step from top to bottom
3. View printed statistics and generated charts
